## 1. Cible : qui contacter

### Profil Client Idéal (ICP)

Promoteurs immobiliers résidentiels qui commercialisent des programmes neufs et ont besoin de **contenu de projection** pour vendre sur plan. Leur douleur : les acheteurs ne se projettent pas avec des plans 2D et des perspectives statiques.

### Critères de qualification

- Commercialise du neuf (résidentiel ou mixte)
- Programme en phase de lancement ou pré-commercialisation
- Présent sur LinkedIn (publie ou commente)
- Équipe marketing de 1 à 10 pers. (décision rapide)
- Zone : Île-de-France, Lyon, Bordeaux, Nice, Montpellier

### Interlocuteurs cibles

- **Directeur commercial / de la commercialisation**
- **Responsable marketing / communication**
- Directeur de programmes
- Fondateur / DG (promoteurs < 50 pers.)

| Nexity | 5,2 Md€ CA | Moyenne | Grands comptes = cycle long. Cibler les directeurs de programme locaux IDF. |

## 2. Préparer ton profil personnel

Ton profil perso est ta page de vente. Avant d'envoyer le premier message, il doit répondre à : **« pourquoi cette personne me contacte, et est-elle crédible ? »**

- [ ] **Titre LinkedIn** : *« Je crée des vidéos immobilières IA qui font réserver des visites — Fondatrice PROD'AI »*
- [ ] **Bannière** : visuel avant/après (6 photos → vidéo) avec le logo PROD'AI
- [ ] **Section « À propos »** : 3 paragraphes max — problème du marché, ta solution, preuve (cas Cherpantier ou FREDēLION)
- [ ] **Sélection de contenus** : épingler la vidéo FREDēLION et le carrousel système IA

> **Synergie** : Le prospect reçoit ton message → clique sur ton profil → voit PROD'AI → clique sur la page → voit les vidéos. **Profil qui prospecte + page qui rassure.**

## 3. Séquence de messages (4 touches / 14 jours)

### Jour 0 — Préparation : Engagement silencieux

Like et commente 2-3 posts du prospect. Un commentaire pertinent de 2 phrases, pas un emoji. Objectif : que ton nom apparaisse avant ta demande.

### Jour 1 — Demande de connexion : Note personnalisée

```
Bonjour {Prénom},

Je viens de voir le lancement de {nom du programme} — le positionnement 
sur {quartier/segment} est très bien pensé. Je travaille sur le contenu 
vidéo IA pour la promotion immobilière, j'aimerais échanger.
```

**Variante** (quand pas de programme identifié) :
```
Bonjour {Prénom},

Je suis votre travail chez {entreprise} depuis un moment. Je m'intéresse 
à la manière dont les promoteurs utilisent la vidéo pour commercialiser 
le neuf — j'aimerais échanger.
```

### Jour 3 — Message de valeur : Partage de résultat, pas de pitch

```
Merci pour la connexion {Prénom}.

Je voulais partager un retour d'expérience : on a transformé 6 photos 
d'annonce en vidéo immersive pour un bien à Paris 16e — sans tournage, 
livré en deux jours. Le format plein écran a généré un taux de clic 
3x supérieur aux photos classiques.

Si le sujet vous parle, je peux vous montrer le résultat en 10 minutes.
```

### Jour 7 — Relance douce : Question ouverte

```
{Prénom}, une question rapide : sur vos programmes en commercialisation, 
les acheteurs arrivent-ils à se projeter avec les visuels actuels 
(plans, perspectives 3D) ou vous constatez un décalage ?

C'est le problème que nos vidéos IA résolvent — heureux d'en discuter 
si le sujet est d'actualité chez vous.
```

### Jour 14 — Dernière relance : Fermeture propre

```
{Prénom}, je ne veux pas insister — je comprends que le timing 
n'est peut-être pas le bon.

Si un jour vous cherchez à tester un format vidéo différent pour 
vos programmes, je serai là. Bonne continuation !
```

## 4. L'offre démo

### Format de la démo gratuite

Transformation de 2 à 4 photos d'un de leurs programmes en une vidéo immersive de 15-30 secondes. **Gratuit. Livré sous 48h.** Ils n'ont qu'à envoyer les photos.

→ Le promoteur voit le résultat sur *son propre bien*. Coût pour toi : 30 min. Valeur perçue : énorme.

### Déroulé de l'appel démo (10 min)

1. 2 min — écouter leur contexte (quel programme, quel stade)
2. 3 min — montrer la vidéo FREDēLION ou Cherpantier
3. 2 min — expliquer le process (photos → vidéo IA → 48h)
4. 3 min — proposer le test gratuit et convenir de la suite

## 7. Comment trouver les prospects

### Recherches LinkedIn

```
"directeur commercial" promoteur immobilier
"responsable marketing" promotion immobilière
"directeur de programmes" immobilier neuf
```

Ou : page LinkedIn du promoteur → onglet « Personnes » → filtrer par poste.

### Sources complémentaires

- **FPI** (Fédération des Promoteurs Immobiliers) — annuaire des adhérents
- **Immoweek, Le Moniteur** — actualité des lancements de programmes
- **Google Maps** — « promoteur immobilier + [ville] » pour les PME locales
- **Commentaires LinkedIn** — les gens qui commentent les posts de programmes sont souvent dans le métier

## 8. Page PROD'AI — rôle et contenu

La page company ne prospecte pas. Elle rassure le prospect après ton message.

- [ ] **Vidéos démo** — meilleurs résultats (FREDēLION, Cherpantier, duplex)
- [ ] **Posts éducatifs** — comme le carrousel « du chat aux agents IA »
- [ ] **Retours d'expérience** — les posts « journal de labo » avec résultats
- [ ] **Fréquence** — 2-3 posts/semaine pour que la page ait l'air active

> **Circuit du prospect** : message reçu → profil → PROD'AI → vidéos → « elle sait faire » → il répond. Page vide = circuit cassé.
