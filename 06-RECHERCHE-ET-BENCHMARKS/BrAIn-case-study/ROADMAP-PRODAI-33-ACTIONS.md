# 🗺️ Roadmap Prod'AI — 33 Actions

> Tout ce qu'il faut construire pour compléter Prod'AI, inspiré de l'analyse brAIn Ecosystème.
> Classé par priorité. Chaque tâche est taguée : `🧠 brAIn` (inspiré du modèle brAIn), `🟠 Prod'AI` (propre à Prod'AI), `🔴 Urgent`.

## Phase 1 — Urgences : Fermer les preuves (5 tâches)

Avant de construire quoi que ce soit de neuf : verrouiller la crédibilité. Pas de landing page sans preuve.

- [ ] **🔴 Fermer le cas Cherpantier** — Relancer, signer, livrer la vidéo cinématique. C'est LE cas d'étude qui débloque tout le reste.
- [ ] **🔴 Filmer 3 témoignages vidéo** — Même informels (Loom 2 min). Contacts immo existants, anciens clients conciergerie, collègues. Demander : quel problème, quel résultat.
- [ ] **🧠 Créer un compte Trustpilot Prod'AI** — Envoyer le lien d'avis à chaque personne qui a interagi avec toi en pro. Même 5 avis à 5 étoiles changent la donne.
- [ ] **🟠 Compiler les chiffres réels** — 12 biens gérés, 10 ans d'expérience immo, X vidéos produites, X automatisations livrées. Chiffres honnêtes > pas de chiffres.
- [ ] **🟠 Documenter le cas Bubble (laverie) comme portfolio** — Le packager proprement : contexte, méthode, résultat. Même exercice = preuve de compétence.

## Phase 2 — Fondations : Offre & Tunnel (6 tâches)

Structurer l'offre en 3 niveaux, poser le tunnel de vente automatisé, productiser les templates.

- [ ] **🧠 Structurer l'offre en 3 niveaux** — Autonomie (formation Qualiopi, tu apprends seul) → Accélération (done-with-you, on construit ensemble) → Délégation (done-for-you, on gère tout). Chaque niveau avec son prix et sa promesse.
- [ ] **🧠 Mettre en place le call de qualification** — Calendly ou iClosed avec 3 questions filtre : taille du portefeuille, budget mensuel marketing, urgence du besoin. Fin du « contactez-moi par email ».
- [ ] **🟠 Construire la landing page Prod'AI** — Structure inspirée brAIn : hero + chiffres + avant/après + offre 3 niveaux + témoignages + FAQ + CTA call. Héberger sur Webflow (édition manuelle + domaine OVH).
- [ ] **🧠 Créer le tableau Avant / Avec Prod'AI** — Avant : photos floues sur SeLoger, 0 leads, pas de vidéo, tout fait à la main. Avec : vidéo cinématique, leads qualifiés, closing automatisé, contenu à la chaîne.
- [ ] **🧠 Séquence email post-appel (3 emails)** — Email 1 : récap de l'appel + cas d'étude. Email 2 : témoignage vidéo. Email 3 : offre limitée ou bonus. Automatiser via n8n ou Brevo.
- [ ] **🟠 Créer le lead magnet « Checklist IA pour agences immo »** — PDF 1 page : 10 points à vérifier pour savoir si l'IA peut booster ton agence. Gate derrière le formulaire n8n existant.

## Phase 3 — Library : Templates immo-spécifiques (10 tâches)

25 templates hyper-ciblés immobilier > 300 templates généralistes. Chaque template = une mission que tu as déjà faite.

- [ ] **🟠 Template Reel listing 30 secondes** — Prompt image (NanoBanana/Midjourney) + prompt animation (Kling/Seedance) + script voiceover + montage CapCut. Basé sur ton workflow Cherpantier.
- [ ] **🟠 Template email acquéreur personnalisé** — Prompt ChatGPT/Claude qui génère un email de relance acquéreur à partir de 3 infos (bien, budget, critères). Intégrable dans n8n.
- [ ] **🟠 Template automatisation check-in Airbnb/Booking** — Workflow n8n : réservation confirmée → message personnalisé → instructions d'accès → rappel J-1. Issu de ton système actuel.
- [ ] **🟠 Template valorisation bien par IA** — Prompt structuré : 5 photos + localisation + surface → description premium du bien + estimation du positionnement marché.
- [ ] **🟠 Template réponse commentaire Instagram immo** — Prompt + automatisation ChatPlace : détecte les mots-clés (visite, prix, dispo) → DM personnalisé → lien formulaire.
- [ ] **🟠 Template script vidéo « visite virtuelle »** — Structure en 5 actes (accroche, extérieur, pièce à vivre, argument unique, CTA) avec prompts de génération image + animation par acte.
- [ ] **🧠 Template audit IA pour agence immo** — Questionnaire structuré (15 questions) + grille d'évaluation automatique + recommandation personnalisée. Ce que brAIn appelle le « quick win ».
- [ ] **🟠 Template proposition commerciale Prod'AI** — Document type avec cas d'étude intégré, 3 niveaux d'offre, ROI estimé, planning de déploiement. Adapté par client en 10 min.
- [ ] **🟠 Template carrousel LinkedIn « IA × Immo »** — 10 slides type : accroche → problème → solution IA → avant/après → chiffre → CTA. Format Canva réutilisable.
- [ ] **🧠 Template séquence outbound agences immo** — 3 messages LinkedIn + 2 emails de prospection froide ciblant les directeurs d'agence. Ton « copine qui explique », pas commercial.

## Phase 4 — Acquisition : Générer du trafic (8 tâches)

La landing page sans trafic ne sert à rien. Trois canaux à activer en parallèle.

- [ ] **🟠 Contenu LinkedIn B2B — 3 posts/semaine** — Alterner : cas d'étude Prod'AI, coulisse de production IA, conseil actionnable immo+IA, témoignage client. Ton « journal d'une Product Builder ».
- [ ] **🟠 Instagram Reels @neva_affair — 2 Reels/semaine** — Reels 15-30s montrant le process : avant/après d'un listing, coulisse CapCut, résultat final. CTA vers le lead magnet.
- [ ] **🟠 Automatiser le CTA « Commentez VIDÉO »** — Tu as déjà le workflow ChatPlace + formulaire n8n. L'étendre à chaque nouveau Reel automatiquement. Chaque commentaire = lead capté.
- [ ] **🟠 SEO landing page — 5 pages piliers** — Créer des sous-pages : « IA pour agences immobilières », « Vidéo IA immobilier luxe », « Automatisation agence immo », « Formation IA immobilier », « Conciergerie digitale ». Trafic organique long terme.
- [ ] **🧠 Meta Ads — test 50 €/semaine** — Une campagne : vidéo Reel (celle qui a le mieux marché en organique) → landing page → call Calendly. Audience : directeurs agences immo, France, 30-55 ans.
- [ ] **🧠 Webinaire mensuel « L'IA qui transforme l'immobilier »** — 45 min : 30 min de contenu (démo live création Reel IA) + 15 min Q&A. Inscription = lead qualifié. Replay en accès gated.
- [ ] **🟠 Partenariats réseaux immo** — Contacter 3-5 réseaux/franchises immo (Century 21, Orpi, IAD…) pour proposer une formation pilote IA. Qualiopi = financement OPCO = argument massue.
- [ ] **🧠 Outbound LinkedIn ciblé** — Identifier 50 directeurs d'agence sur LinkedIn. Séquence 3 messages (connexion → valeur → proposition d'appel). Utiliser les templates de la Phase 3.

## Phase 5 — Communauté : Le cercle Prod'AI (4 tâches)

Pas 450 membres comme brAIn. 15-20 pros immo qui échangent leads et cas. Qualité > volume.

- [ ] **🧠 Créer un groupe Telegram/WhatsApp fermé** — Inviter les 5-10 premiers clients/contacts immo formés ou accompagnés. Règle : chaque membre partage 1 lead ou 1 cas par mois.
- [ ] **🧠 Mettre en place le lead sharing vertical** — Quand un membre reçoit une demande hors de sa zone/spécialité → il la redirige dans le groupe. Tu prends 10-15 % de commission sur les missions signées.
- [ ] **🧠 Créer le « Kit de lancement Prod'AI »** — Pour chaque client formation : templates brandés co-signés, cas d'études à réutiliser, badge « Formé par Prod'AI ». La mécanique « Brand dès J1 » de brAIn adaptée.
- [ ] **🧠 Organiser 1 live mensuel pour la communauté** — Hot seat : un membre présente son cas, les autres + toi donnent du feedback. 45 min max. Crée de l'engagement et de la rétention.
