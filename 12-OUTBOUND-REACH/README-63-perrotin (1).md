## Déclinaison par typologie

- **Studio** → cible investisseurs, prix d'appel 216K
- **2-3 pièces** → cible jeunes couples, gamme intermédiaire
- **4-5 pièces** → cible familles, gamme haute

## Formats avatar

- **Avatar guide intérieur** : 60-90 sec, l'avatar marche dans les pièces 3D et commente
- **Avatar vendeur face caméra** : 30 sec, buste + pitch commercial
- **Visite narrée combinée** : avatar + voix off IA, format premium

- Split screen (fixe vs animé)
